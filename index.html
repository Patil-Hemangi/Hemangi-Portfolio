SignBridge
Devpost ↗ GitHub ↗

Real-time, two-way sign language translation for Deaf and hearing users. Speech goes in, gets converted to proper ASL grammar using NLTK (ASL word order is different from English), then plays from a 150+ sign clip library with fingerspelling as fallback. On the other side, MediaPipe Hands tracks 21 joint landmarks per hand at 30+ fps, Gemini Vision reads the gesture and returns English text in 300-600ms, spoken out via ElevenLabs. There's a side-by-side live conversation mode so both people can communicate in real time without needing an interpreter.

BayShield
Devpost ↗

Disaster response system for Tampa Bay using four AI agents running in parallel: Storm Watcher, Vulnerability Mapper, Resource Allocator, and Alert/Response. They coordinate with each other and self-correct. Built a live dashboard with risk zone maps, shelter capacity tracking, and evacuation routing. We ran it on real Hurricane Helene data from Kaggle, with a RAG pipeline to keep responses grounded. The idea was to help emergency managers make faster decisions when things are moving faster than people can keep up.

NeuroTask — Digitization of Neurological Assessments

A Flutter app to digitize neurological assessments that clinicians currently run on paper. The core requirement was millisecond-level timestamping to accurately capture reaction time, completion latency, and speech onset latency. The UI is built to match the paper tasks exactly so the assessments stay clinically valid. Session data logs to Firebase Firestore and exports as CSV for analysis. Still in active development at USF.
